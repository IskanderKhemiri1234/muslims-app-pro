# Mumin Pro — reference UI assets

Upload the image files from the approved reference design into this folder using these exact filenames:

- `icon_quran.png` — open Quran icon
- `icon_azkar.png` — mosque / Azkar icon
- `icon_kaaba.png` — Kaaba icon (the reference's third shortcut)
- `icon_qibla.png` — compass / Qibla icon
- `icon_tasbih.png` — prayer beads / Tasbih icon
- `banner_mumin_pro.webp` — lower promotional banner with mosque and Quran

Recommended: transparent PNG for the five standalone icons; WebP for the banner. Keep each icon as its own image file. Do not upload one combined screenshot in place of the individual assets.

The directory is registered in `pubspec.yaml` as a Flutter asset directory.
